# AICTE Demo Portal — Only Front End

Frontend-only mock AICTE portal built with HTML, CSS, JavaScript, Bootstrap 5, and Bootstrap Icons.

## Includes

- Public Home page with Student, Faculty, and Admin portal options
- Role-based Student, Teacher, and Developer demo login flows
- Student, Faculty, and Admin feature actions
- Simulated authentication, payments, documents, approvals, and admin scenarios
- Centralized action mappings and placeholder API integration

No real authentication, database, payment gateway, document storage, AI, OpenSearch, Slack, or backend logging is included.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://127.0.0.1:4173`.
